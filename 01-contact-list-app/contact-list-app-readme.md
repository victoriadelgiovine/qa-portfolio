# Contact List App

Aplicación web de práctica utilizada para desarrollar y documentar habilidades de testing manual.

**URL de la aplicación:** [thinking-tester-contact-list.herokuapp.com](https://thinking-tester-contact-list.herokuapp.com/)

## Módulos testeados

- Autenticación (login y registro)
- Gestión de contactos (crear, editar, eliminar)
