# Plan de Pruebas - Contact List App

**Proyecto:** Contact List App  
**URL:** https://thinking-tester-contact-list.herokuapp.com  
**Fecha:** Junio 2026  
**Responsable:** Victoria Paula  

## Alcance

### Qué se testea
- Módulo /contactList
- Flujos de agregar, editar y eliminar contactos
- Validaciones de campos obligatorios y formatos
- Módulo de autenticación (login y registro)

### Qué no se testea
- Performance
- Seguridad avanzada
- Compatibilidad con múltiples navegadores

## Objetivos
- Verificar que cada campo acepte el tipo de dato correspondiente
- Verificar mensajes de error ante campos vacíos o formatos inválidos
- Verificar que agregar, editar y eliminar contactos funcione correctamente
- Verificar que el flujo E2E completo sea exitoso

## Criterios de entrada
- Última versión del software disponible en el entorno de pruebas
- Datos de prueba disponibles
- Entorno de testing estable y accesible

## Criterios de salida
- 100% de casos de prueba ejecutados
- 0 bugs críticos o bloqueantes abiertos
- Bugs de severidad media documentados y aceptados

## Herramientas
- Gestión de pruebas: Google Sheets
- Reporte de bugs: Jira
- Documentación: Confluence
- Navegador: Chrome 148.0 / Windows 11
