# QA Portfolio - Victoria Paula Del Giovine

## Sobre mí
QA Tester en formación con base en Madrid. 
Provengo del área de atención al cliente donde desarrollé 
habilidades de comunicación y orientación al usuario que 
aplico directamente al testing de software.

Formación en Talento Lab (Argentina) complementada con 
práctica intensiva en testing manual, API testing y 
automatización con Playwright.

## Stack técnico

- **Testing manual:** casos de prueba, reportes de bugs, planes de prueba
- **Gestión:** Jira, Confluence, Zephyr, GitHub Projects
- **API Testing:** Postman
- **Performance testing:** Postman (Collection Runner — Performance testing, Mock Servers)
- **Automatización:** Playwright + TypeScript (en progreso)
- **Bases de datos:** SQL básico (en progreso)
- **Metodologías:** Scrum / Agile

### App BiT (No Country — Proyecto en Equipo)
Web app B2G (Business to Government) que consolida datos públicos de movilidad, empleo y salud mental por región, con agente de IA para consultas en lenguaje natural. Desarrollada en equipo (11 personas) durante una simulación laboral ágil de 5 semanas.

- Diseño y ejecución de la mayor parte de la suite de casos de prueba funcionales del proyecto (interfaz, mapa, chat, agente de IA, manejo de errores)
- Definición de criterios de aceptación de performance ante ausencia de lineamientos formales del negocio
- Testing de estabilidad del endpoint de IA, con hallazgo documentado de latencia fuera de umbral
- Diseño de 4 plantillas de GitHub Issues (caso de prueba, caso de prueba de performance, reporte de bug, épica/historia de usuario) adoptadas por todo el equipo
- Presentación del trabajo de QA en la demo final del proyecto
